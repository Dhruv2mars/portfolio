# Dhruv Sharma — Portfolio

Personal site at [dhruv2mars.com](https://dhruv2mars.com).

## Deploy

Production and PR previews ship from the Vercel project **`dhruv2mars`** (domain: `dhruv2mars.com`). See [ADR-0004](docs/adr/0004-canonical-vercel-project.md).

## Stack

- Next.js (App Router)
- React
- Tailwind CSS
- TypeScript
- Geist
- bun

## Scripts

```bash
bun install
bun run dev
bun test
bun run build
```
