# Dhruv Sharma — Portfolio

Personal site at [dhruv2mars.com](https://dhruv2mars.com).

## Deploy

Production and PR previews ship from the Vercel project **`dhruv2mars`** (domain: `dhruv2mars.com`). Release review uses the stable `main` Preview domain described in [the release process](docs/release-process.md). See [ADR-0004](docs/adr/0004-canonical-vercel-project.md) and [ADR-0006](docs/adr/0006-preview-first-release-lane.md).

## Stack

- Next.js (App Router)
- React
- Tailwind CSS
- TypeScript
- Geist
- bun
