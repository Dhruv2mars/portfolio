Wordmark studio

Dither a mark and export the coordinates. The ink can be text set in any typeface, or a drawing you load — a wordmark from Figma or Illustrator, exported as SVG or PNG, gets read the same way, so the mark need not be a typeface at all. The first stage is the footer's signature section drawn at true size for the device you pick — the same width, the same height, the same crop at the bottom edge — so what you judge there is what ships. The second stage shows the whole box including the part that falls off the page. Both react to the cursor exactly as the footer does.

Export writes the whole of lib/wordmark-dots.ts. The mark is baked to coordinates, so nothing at runtime can re-letter or re-draw it — the preset in the file's header is what you paste back here to pick the work up again. A preset names the artwork it came from but cannot carry it, so load the image again first.
