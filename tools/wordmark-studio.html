Move the sliders until the dithered mark matches the drawn one, then export. The top stage is the shipped size at the width you give it; the bottom stage is the same dots blown up so you can see the grain. Both react to the cursor exactly as the footer does.

Export writes the whole of lib/wordmark-dots.ts. To make the checked-in file reproducible from the repository, paste the preset back into DEFAULTS in tools/dither.js and run bun tools/gen-dots.mjs > lib/wordmark-dots.ts.
