# Canonical Vercel project is `dhruv2mars`

This GitHub repo (`Dhruv2mars/portfolio`) deploys through the Vercel project named **`dhruv2mars`** — the one that owns `dhruv2mars.com` / `www.dhruv2mars.com`. A second Vercel project also named `portfolio` was briefly linked to the same repo and produced duplicate preview deployments without the production domain; it was unlinked and removed.

**Do not** create or reconnect another Vercel project to this repo. Local CLI link (`.vercel/`, gitignored) and GitHub integration must target `dhruv2mars` only.
