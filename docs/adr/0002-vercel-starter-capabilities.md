# Adopt Vercel portfolio-blog starter capabilities

The redesign takes the Vercel portfolio blog starter’s capability set as the baseline (MDX Writings, RSS, sitemap/robots/JSON-LD, dynamic OG images, syntax highlighting, Tailwind, Geist, Vercel Analytics + Speed Insights) and maps it onto our IA (Home, Writings, Projects, AI Activity). We are not forking their visual layout wholesale — Editorial surface and our section model own the design.

Since superseded in part: AI Activity is no longer a section of the IA. The data is drawn as the
hero figure on Home instead — see ADR-0007.
